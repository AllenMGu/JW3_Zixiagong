# 紫霞功 PVE 双键宏（2026-09-28 正式服草案）

> 依据用户 2026-09-28 当前技能、奇穴截图独立设计。适用于截图中的浮生／同尘／固本／抱阳／正气配置。宏条件写法参考[剑网3官方攻略站的宏规则](https://jx3.xoyo.com/show-4489-257-1.html)。**未在游戏客户端或木桩实测**；当前增益名与落点行为需核对。

## 1. 循环键

```text
/cast [nobuff:气剑|bufftime:气剑<2] 万世不竭
/cast 六合独尊
/cast [qidian>9] 两仪化形
/cast [qidian<2] 太极无极
/cast 四象轮回
```

这五行是原循环键：无气剑时读万世一段，气剑临期打二段；六合可用时维持剑域；满五格气打两仪；低气时太极、四象续气。**开始爆发时先不要按循环键**，否则无气剑时万世一段可能先生成 5 柄气剑，使固本开紫气赠送的气剑溢出。

## 2. 爆发键

```text
/cast [nobuff:破苍穹] 破苍穹
/cast [buff:破苍穹&nobuff:气剑] 紫气东来
/cast [buff:紫气东来&qidian>9] 五方行尽
```

**使用顺序**：目标站稳、身上没有气剑时，连续按爆发键：先在能覆盖自己和目标的位置放破苍穹；身处气场时开紫气东来；紫气聚满气后，将五方行尽的目标点放在破苍穹气场内。五方落点技能若弹出选点光标，还需鼠标点一下位置。完成后继续按循环键，六合也由循环键处理。

这里特意把紫气放在五方**之前**：用户当前“正气”截图写明，五方行尽施展时若目标点有破苍穹，会吞噬该气场并形成短时伤害区域；抱阳则要求处在破苍穹气场内施展紫气，才能得到对应的收益。上一版文档把五方放在紫气前面，顺序不对，已更正。

## 为什么用两个键

内置宏有 128 字符限制，而且破苍穹、五方行尽可能需要选落点。爆发键只在需要开爆发时按，避免紫气东来在转火、首领离场或气剑满时被循环键提前施展。循环键和爆发键的正文分别少于 128 字符；复制代码框内的命令行即可。一个按键不会自动连点，需要玩家继续按键。

## 木桩核对

1. 先检查当前增益栏的名称是否真是“气剑”“破苍穹”“紫气东来”；若名称不符，把宏里相应名称改成游戏显示的名称。不要只凭 tooltip 的引号判断宏可识别。
2. 空气剑按爆发键，确认场、紫气、五方依次成功。紫气是否立即聚满气、五方是否需要点地面，以当前客户端为准；若五方没有落在破苍穹上，就无法得到正气的气场联动。
3. 爆发后切循环键，确认万世不会立刻消耗固本送的 5 柄气剑，剩余时间接近 2 秒再施展二段。
4. 若六合弹出地面选点而卡住循环，将 `/cast 六合独尊` 移出循环键，改为手动在目标位置施展。
5. 观察宏是否误判增益、两仪是否只在满气时触发；必要时按战斗记录调整阈值。

这是可复制的技能优先级与爆发键设计，尚未经当前客户端实战验证；不将它描述为最优伤害轴。
