# 紫霞功 PVE 循环宏草案

- 版本基线：2026-09-28，旗舰端正式服 1.5.0.9971。
- 目标：用一个循环键处理“积气—消耗”的基础单体循环；关键资源和落点技能仍由玩家控制。
- 来源：按用户提供的当前技能 tooltip 自行整理，没有复制其他玩家的宏代码。
- 状态：**待游戏内木桩验证**。当前截图没有清晰显示万世不竭二段触发/消耗条件，因此不把它写成自动触发规则。

## 基础循环键

```
/cast 两仪化形
/cast 四象轮回
```

设计依据：四象轮回用于运功和续气；两仪化形消耗气量、气量越高伤害越高。宏先尝试消耗招式；条件不足时由四象轮回补充气量。命令行按顺序尝试技能，使用时先在木桩确认客户端的无效技能会继续尝试下一行。

## 保留手动按键

| 技能 | 为什么保留手动 |
|---|---|
| 万世不竭 | 一段/二段与气剑资源有关；当前截图没有完整显示二段触发、气剑消耗及何时刷新。 |
| 六合独尊 | 需要把八方剑域放在有效目标区域；落点由玩家选择。 |
| 五方行尽 | 需要考虑目标位置和当前气量，不让控制/落点效果浪费。 |
| 紫气东来 | 爆发资源；手动选择时机，避免在剑域/会神窗口外提前开启。 |
| 破苍穹、生太极 | 气场需按团队位置、覆盖和目标位置放置；生太极截图显示脱战调息与战斗调息不同。 |

## 爆发操作顺序（按键操作，不是连发宏）

1. 开怪前按需放置破苍穹；确认团队站位后放生太极。
2. 目标固定、剑域落点有效时施展六合独尊。
3. 配合破苍穹和当前奇穴使用五方行尽。
4. 确认剑域与输出窗口已建立后再开紫气东来。
5. 紫气期间用基础循环；万世不竭一段/二段按气剑状态手动处理。

这套顺序是按技能作用与当前 PVE 配置推导的第一版，**不是声称已经木桩测过的最优轴**。移动战、首领机制、奇穴变化时应调整落点和紫气时机。

## 木桩验证清单

- 确认两仪化形气量不足时，宏会继续执行四象轮回；有气时不会被下一行覆盖。
- 记录 3 分钟战斗中四象轮回、两仪化形、万世不竭的施展次数和伤害。
- 观察万世不竭气剑是否过期或溢出；根据实测再决定是否加入气剑剩余时间条件。
- 检查紫气东来是否覆盖剑域/五方行尽窗口。
- 当前截图中生太极 tooltip 为 10 秒调息，与 2026-01-19 调整记录为 15 秒不一致；在确认当前角色技能状态前，不把生太极加入自动宏。

## 使用边界

- 这是核心循环草案；不含自动连点、鼠标驱动脚本或按键精灵。
- 没有经过游戏内验证前，不应把宏当作完整或最优输出方案。
- 测试时若出现技能被跳过、两仪过早消耗或万世气剑过期，应先回报木桩记录，再改优先级和条件。
