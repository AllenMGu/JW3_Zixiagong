# 紫霞功奇穴资料（旗舰端正式服）

核对基线：2026-09-28，正式服 1.5.0.9971。当前九个选中奇穴及其 tooltip 可从用户当天截图辨认；下文保留其他奇穴的历史调整线索，但不冒充完整可选奇穴树。奇穴层位可能随赛季变化。

## 当前截图对应的单体 PVE 方案

当前武学方案界面显示选中：**浮生 / 同尘 / 跬步 / 归元 / 心固 / 固本 / 破势 / 正气 / 抱阳**。这不是根据别人的循环照抄：以下分别核对截图里的技能说明，再由它们之间的先后依赖推导[实战方案](macros.md)。界面没有列全每个层位的其他候选，因此不把这套宣称为任意装备、任意首领的最优解。

| 当前选择 | 截图可读的作用 | 在这套方案里的用法 |
|---|---|---|
| 浮生＋同尘 | 六合的八方剑域可脱手，附着敌方随之移动；每次攻击令下一次伤害额外提高 50%。 | 用于持续伤害，且在正气的 6 秒区间由六合命中触发额外伤害；首领免控时忽略定身加伤。 |
| 跬步 | 每柄气剑使四象、两仪、万世伤害提高 5%，五剑共 25%。 | 紫气得剑后尽量保留五剑，让主力伤害吃满加成。 |
| 归元 | 破苍穹变为无需运功、只对自己生效；在破苍穹期间无视目标 60% 内功防御。 | 先享受破苍穹覆盖，再用正气五方吞场。 |
| 心固 | 四象可移动运功，运功时间少 0.25 秒；命中额外续 1.5 格气。 | 用四象迅速回到满五格，再打两仪。 |
| 固本 | 紫气调息减少 18 秒；施放后立即获得五柄气剑，持续期额外 30% 无双等级。 | 不要在紫气前用万世一段占满剑。 |
| 破势 | 镇山河调息少 2 分钟；不生成保护场，施放时强化当前气剑，使气剑和万世二段对非侠士目标伤害提高 130%，持续 3 分钟。 | 紫气给出五剑后用镇山河；不能再靠它保护团队。 |
| 正气 | 五方调息增加 5 秒，命中破苍穹气场会吞场并生成 6 秒颠越苍穹；该区域被五方、六合命中可额外触发伤害，最多 5 次。 | 在紫气中后段吞场，立刻让六合打进区域。 |
| 抱阳 | 破苍穹持续时间增加 12 秒、自身增益提高 100%；在场内施放紫气时，紫气会心几率收益减少 15%、会心效果额外增加 30%。 | 紫气先在场内开，再选时机让五方吞掉场。 |

## 历史资料：2026-04-23 玩家攻略使用的 PVE 方案

用户提供的《【暗影千机】紫霞功-紫武循环详解》截图列出一套**浮生流、紫武、九个常规选择**：`浮生 / 同尘 / 跬步 / 归元 / 心固 / 固本 / 抱阳 / 正气 / 破势`。这是作者当时的 PVE 方案，**不代表 9 月 28 日全部奇穴树，也不是所有装备通用的最优解**。

| 奇穴 | 截图所述作用 | 版本与适用边界 |
|---|---|---|
| 浮生 | 六合独尊改为可脱手放置的输出形式。 | 此攻略循环的核心，非通用六合机制。 |
| 同尘 | 六合剑域附着目标，可随目标移动；逐次伤害递增提高到 50%。 | 与 2026-03-31 调整记录吻合，依赖浮生。 |
| 跬步 | 每柄气剑提高四象轮回、两仪化形、万世不竭伤害；攻略以每柄 5%、五柄共 25% 解释。 | 属 4 月攻略的奇穴描述；9 月面板待核。 |
| 归元 | 作者列为输出选择；9 月 28 日截图明确：破苍穹仅对自身生效，其持续期无视目标 60% 内功防御。 | 当前效果见上方实战方案。 |
| 心固 | 截图明确：四象可移动运功、运功时间少 0.25 秒、命中额外续 1.5 格气。 | 减时为当前奇穴 tooltip，并非反推的基础读条。 |
| 固本 | 紫气东来减少 18 秒调息，开紫气获 5 柄万世气剑，并增加持续期间的无双收益。 | 与 2026-04-13 调整文字相互印证；作者配置中紫气调息约 57 秒。 |
| 抱阳（混选） | 破苍穹延长 12 秒，增强自身气场收益，并改变气场内紫气的会心、会效。 | 与 2026-03-31 调整记录相符。 |
| 正气（混选） | 当前截图可见：五方行尽命中破苍穹气场的目标点时，会吞噬该气场并生成短时伤害区域。 | 抱阳要求在破苍穹气场内施展紫气以获得修饰收益，所以爆发顺序应为先紫气、后五方；输出覆盖仍取决于落点与首领移动。 |
| 破势（混选） | 当前 tooltip 明示镇山河不生成气场，强化施放时已有气剑，使气剑和万世二段对非侠士目标伤害提高 130%，持续 3 分钟。 | 这套选穴的镇山河不能承担保护场用途。 |

该攻略明确指出：2026 年 4 月赛季移除了原“绝云”相关的八格气玩法，不能把历史“八豆两仪”宏套入该方案。截图作者的属性、装备及延迟会影响具体收益，奇穴作用应再与目前正式服面板逐项对照。

## 版本隔离

“苍生铸世”9 月武学调整目前归入**测试服计划**。9 月 24 日官方测试服更新说明写明新一轮武学调整已在测试服上线，最终效果以正式服上线为准。因此：

1. 当前的正式服奇穴搭配和宏，不使用测试服“飞剑→万世不竭二段”的预告机制作为既成事实。
2. 不将测试服的“浮生”“洞渊”“散华”层位和新数值覆盖到本表。
3. 等正式服公告和角色面板更新后，另开版本资料并核对每一重的实际选项、效果与前置。
