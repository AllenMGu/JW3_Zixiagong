## 当前单体 PVE 选穴

`浮生 / 同尘 / 跬步 / 归元 / 心固 / 固本 / 破势 / 正气 / 抱阳`

固本开紫气立即给五柄气剑；破势的镇山河强化当时已有的气剑；先站在破苍穹内开紫气获得抱阳收益，随后五方吞场生成颠越苍穹，再让六合命中触发正气的额外伤害。首领免控时不计同尘的定身／眩晕加伤。

## 两个宏

宏需要连续按。**B 用于准备爆发及紫气期间**，**A 用于平稳输出和五方之后**；五方落点、镇山河和万世不竭的剑数时机由玩家手动控制。

**A：平稳输出／五方之后**

```text
/cast 六合独尊
/cast [qidian>9] 两仪化形
/cast 四象轮回
```

**B：破苍穹＋紫气准备**

```text
/cast [nobuff:破苍穹] 破苍穹
/cast 紫气东来
/cast [qidian>9] 两仪化形
/cast 四象轮回
```

B 每按一次只会施放一个可用招式：第一次按下放破苍穹后，先确认自己站进气场，**再继续按 B** 才会开紫气。紫气不再依赖未验证的 `bufftime:破苍穹` 判断；如果第一行反复铺场、仍开不出紫气，按[木桩核对步骤](docs/macros.md#木桩验证与回退)处理。

起手按 B 放破苍穹，确认站入场内后继续按 B 开紫气；固本给出五剑后，镇山河转好才手动按一次。继续 B 打满气两仪／四象；紫气中后段手动五方吞场，立即切 A，A 会优先施放六合。接近下一次爆发时提前切 B，避免 A 在五方之前用掉六合。更多细节见[宏方案](docs/macros.md)。
