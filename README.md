## 当前单体 PVE 选穴

`浮生 / 同尘 / 跬步 / 归元 / 心固 / 固本 / 破势 / 正气 / 抱阳`

固本开紫气给五剑；镇山河在破势下强化已有气剑；先在破苍穹内开紫气，五方吞场后让六合命中颠越苍穹。首领免控时不计同尘的控制加伤。

## 推荐：双键完整循环

游戏宏每按一次只选一招，需持续按键。A 负责平稳期的**万世／六合／两仪／四象**；B 负责爆发前的**破苍穹／紫气／两仪／四象**。提前约 20 秒从 A 切 B，保留六合并避免临近紫气又自动补剑。

**A：平稳期及五方后**

```text
/cast [bufftime:气剑<2] 万世不竭
/cast [nobuff:气剑] 万世不竭
/cast 六合独尊
/cast [qidian>9] 两仪化形
/cast 四象轮回
```

**B：铺场与紫气**

```text
/cast [nobuff:破苍穹] 破苍穹
/cast 紫气东来
/cast [qidian>9] 两仪化形
/cast 四象轮回
```

起手按 B 放场、继续按 B 开紫气；得到五剑后若镇山河可用，手动按一次。紫气中后段手动五方吞场，立即切 A，让六合优先命中颠越苍穹。万世一／二段的自动判断依赖客户端真实“气剑”增益名与一／二段切换机制，**尚未实测**；若识别不正确，从 A 删掉前两行，万世改手动。五方、镇山河和需要走位补气的太极无极保留手动。

## 单键简化版

如果只想持续按一个宏键，可以用下面这版；它自动处理破苍穹、紫气、六合窗口、两仪和四象，**不能同时可靠处理万世的剑数时机**，非爆发期六合也需手动补。它依赖“紫气东来”“破苍穹”两个自身增益名，须先在木桩验证：

```text
/cast [buff:紫气东来&nobuff:破苍穹] 六合独尊
/cast [nobuff:紫气东来&nobuff:破苍穹] 破苍穹
/cast 紫气东来
/cast [qidian>9] 两仪化形
/cast 四象轮回
```

单键的五方、镇山河、万世仍手动。完整按键顺序和两种方案的风险见[宏说明](docs/macros.md)。
