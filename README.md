## 当前单体 PVE 选穴

`浮生 / 同尘 / 跬步 / 归元 / 心固 / 固本 / 破势 / 正气 / 抱阳`

紫气东来在固本下给五柄气剑；破势镇山河强化已有气剑；归元的破苍穹先提供自身输出收益，正气五方随后吞场，六合命中颠越苍穹触发额外伤害。首领免控时不计定身加伤。

## 在游戏里建立两个宏

打开宏设置，分别新建 **A（平稳）**、**B（爆发）**，将代码框内命令复制进去，并把两个宏拖到快捷栏。每次按键执行当前可施放的一行，需要持续按键。

**A：平稳期**

```text
/cast [nobuff:破苍穹] 破苍穹
/cast [bufftime:气剑<2|nobuff:气剑] 万世不竭
/cast 六合独尊
/cast [qidian>9] 两仪化形
/cast 四象轮回
```

无破苍穹时补场；万世处理临期气剑或无剑状态；六合可用时补剑域；满气两仪，其余四象回气。A 会自动补剑和用六合，临近爆发不要继续按它。

**B：爆发准备与回气**

```text
/cast [nobuff:破苍穹|bufftime:破苍穹<10] 破苍穹
/cast 紫气东来
/cast [qidian>9] 两仪化形
/cast 四象轮回
```

B 会先补／刷新破苍穹，再开紫气；后续用两仪、四象打伤害与回气。**镇山河不在宏内**，因为调息约两分钟。

## 按键流程

1. **起手按 B**，确认破苍穹落点覆盖自己和首领；如果出现地面选点光标，先点击合适位置。再按 B 开紫气、得到五剑。
2. **手动镇山河**：仅当它转好时，在紫气给出五剑后按一次；没转好就继续 B 打两仪、四象。
3. **紫气中后段手动五方行尽**，将落点选在破苍穹场内且覆盖首领；吞场后立即**手动六合独尊**，利用正气约 6 秒的额外伤害窗口。
4. 窗口结束换 **A**。下一次紫气快转好时提前约 20 秒切回 **B**，避免 A 自动用掉六合或补出会与固本赠剑冲突的新剑。旧剑若还在，可先手动万世二段清掉；若紫气已经可用，确认场和旧剑状态后才按 B。

太极无极保留独立快捷键，用于走位或补最后一格气。`qidian>9` 表示五格满气。宏内的“气剑”“破苍穹”增益名、破苍穹选点以及万世一／二段切换**尚未在当前客户端木桩实测**；若宏反复尝试施放破苍穹，先把该行移出宏并手动施放。完整机制与核对步骤见[宏方案](docs/macros.md)。
