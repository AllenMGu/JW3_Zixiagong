## 一个键持续按的循环宏

每按一次只施放一招，需反复按。**万世一段**由宏在无气剑时自动尝试，**万世二段**手动；五方锁定目标后可以直接施放，纳入宏。破势的**镇山河**仍按你的要求手动。

```text
/cast [nobuff:破苍穹] 破苍穹
/cast 紫气东来
/cast [nobuff:气剑] 万世不竭
/cast [buff:紫气东来] 五方行尽
/cast 六合独尊
/cast [qidian>9] 两仪化形
/cast 四象轮回
```

顺序：先铺破苍穹、开紫气；五方只在紫气期间自动尝试，随后六合；满气两仪，否则四象。紫气给出五剑且镇山河可用时，手动按镇山河；五剑临期或需要清剑时，手动万世二段。太极无极用于走位补气，保留手动。

**取舍**：五方会在紫气开启后的首个可用按键较早吞场，且宏可能在五方吞场后先补破苍穹、下一按才尝试六合；因此这是一键方便版，不能保证正气 6 秒窗口的最优时机。自动万世一段依赖客户端将气剑识别为“气剑”，尚需在木桩验证；如果无剑时不补剑或意外触发二段，先删除第三行并手动万世。完整核对步骤及更精确的双键备选见[宏说明](docs/macros.md)。
